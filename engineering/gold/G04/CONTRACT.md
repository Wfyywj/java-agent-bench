# Auth review fixture contract v1
This slice explicitly chooses a synthetic approved SLA of 30 monotonic clock units for cached allow and 5 for deny. Original catalog's unresolved production SLA is NOT resolved by this fixture. Cache keys include tenant, subject, resource and action. Policy version is carried in entries; invalidation versions at least as new remove an entry, older ones cannot evict a newer decision. Dropped invalidations converge via fixed, non-sliding TTL, with exact expiry boundary a miss. Fresh cached grants may serve during authority outage only before expiry; expired grants fail closed. Unavailability is not an authoritative denial and cannot poison later reads. Callers provide authenticated identity in this slice; token validation and distributed consistency are out of scope. Version is not in the lookup key because caller does not know it; entry version + invalidation comparison + bounded freshness establishes the chosen policy. Cache remains enabled; hot hits must avoid remote lookup. Clock values must be monotonic. Map size eviction and load testing remain out of scope.

Frozen public development contract. Assertions derive from these policies, not reference output. This is NOT a hidden holdout. Changing verifier or this contract invalidates comparison.
