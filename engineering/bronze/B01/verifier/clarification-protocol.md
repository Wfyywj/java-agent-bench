# Frozen facilitator contract
Created with the package, before candidate execution. Prompt distribution includes only baseline/ and evidence/ plus PROMPT.md. The evaluator holds this directory separately. Answers are released as an explicit stakeholder reply when the candidate requests clarification, not smuggled into prompt text. Public selfcheck directly tests reference decisions against the frozen machine-readable answers. This is an objective decision-field check, not an assessment of prose quality; evidence-map and delivery quality remain manual/unscored. No claim of hidden evaluation security.
