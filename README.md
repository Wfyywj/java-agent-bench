# Java Agent Bench

面向 Java 服务端的原创分级工程测评实验室，用于比较模型、Skills 与工程工作流。

## 当前状态：建设中

首批目标：青铜、白银、黄金、钻石、王者五档，每档 5 个详细场景设计；独立的可运行 Java 机制任务与验收内核；可视化任务浏览与实验计划。

**设计稿不等于可执行任务；参考解自检不等于模型测评。当前没有模型排名或模型实测成绩。**

## 工程范围

需求澄清、跨仓库定位、实现、测试、Review、故障排查。真实生产工程、隔离执行器、保留测试集与模型实测将逐阶段补齐。

## 测评原则

- 参考解通过、原始缺陷失败、错误修复被检出，才发布可运行任务。
- 固定任务/模型/预算做配对比较，区分模型榜与系统榜。
- 保存任务版本、补丁哈希、环境与原始证据，不伪造结果。
- 公共开发集存在污染风险；本地机制内核不是安全沙箱。
- 不包含公司代码、用户凭据或付费模型调用。
